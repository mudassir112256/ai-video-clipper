# AI Video Clipper

Automatically download long YouTube videos, detect speakers using OpenCV face tracking, pick viral highlights with Gemini AI, and render 9:16 vertical shorts with word-by-word animated captions and custom watermarks.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/mudassir112256/ai-video-clipper/blob/main/ai_clipper.ipynb)

## Features
- **yt-dlp**: High-resolution video downloading.
- **Whisper AI**: Word-level timestamp extraction.
- **Gemini 2.5 Flash**: Context-aware viral moment analysis and title generation.
- **OpenCV**: Automated speaker face-tracking and dynamic 9:16 cropping.
- **FFmpeg & ASS**: Custom animated word-by-word caption rendering and top-centered text watermarking.
- **Google Drive Sync**: Auto-export finished `.mp4` clips directly to Drive storage.
